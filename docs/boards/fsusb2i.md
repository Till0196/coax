# KTV-FSMINI / KTV-FSUSB2/V3（IT9175/IT9179版、バックエンド`fsusb2i`）

| | |
| --- | --- |
| バックエンド | `fsusb2i` |
| 対応OS | Linux / Windows / macOS（直接USB）|
| 伝送方式 | ISDB-T（53000〜859999 kHz）|
| ファームウェア | 要（`it9175-firmware.bin`。[firmware.md](../setup/firmware.md)）|

ITE IT9175／IT9179の1チップを直接制御します。
USBブリッジ、OFDM復調器、チューナーが同じダイに載っており、レジスタ空間も分かれていません（アドレスの16〜23ビットが復調器側を指します）。
そのため復調器とチューナーのドライバーを別に持たず、制御は`internal/coaxd/usb/bridge/it9175`にまとめています。

各OSの前提は[os.md](../setup/os.md)にあります。

| 製品 | VID:PID | チューナー本数 | 伝送方式 |

## 選局

選局のたびに、シンセサイザーの設定値を計算し直します。
使うのは、チップ自身が測ったリファレンス周波数から求めた帯域の境目と、I/Q不平衡の校正値です。
SDRAMを載せた基板では、SDRAMのクロックの高調波が受信中のチャンネルに重ならないよう、チャンネルごとにクロックを設定し直します。

## ファームウェア

`it9175-firmware.bin`（7912バイト、SHA-256 `274e1240396acb65defaf43bade6a719490b09dd102a5469eaf53c0e9201933c`）が必須です。
入手先と置き場所は[firmware.md](../setup/firmware.md)にあります。
DigiBest配布のWindowsドライバーパッケージ（`digibest_tv_2j997.zip`）を`fwextract`に渡すと取り出せます。
入れ子は中身で判別するので、`setup.exe`、`DigiBestDriverInstall.msi`、`Data1.cab`、`IT9175BDA.sys`のどれを渡しても同じ結果になります。
チップがすでにファームウェアで動いているときは、転送を省きます。

`.sys`の中のファームウェアは、`it9175-firmware.bin`の形ではなく、チップへ送るUSBスキャッター書き込みパケットに分けた形で入っています。
各パケットは、`03`、バンク番号、`00`、ブロック数のあとに「アドレス上位、アドレス下位、長さ」の記述子がブロック数だけ並び、その後ろに記述子と逆の順でデータが続きます。
1パケットは44バイトまでなので、元のブロックは細かく分かれています。
記述子を読んで、アドレスが続いているかけらをつなぎ直すと、元のバンク／ブロックの形に戻ります。
IT930xの`it930x-firmware.bin`も同じ形式です（[px4.md](px4.md)）。

## 信号測定

C/Nと信号強度は、どちらもIT9175の統計レジスタから読みます。
C/Nは1dB単位、信号強度はdBmです。

## 制限事項

受信できるのはISDB-Tだけで、周波数は53000〜859999kHzの範囲です。
