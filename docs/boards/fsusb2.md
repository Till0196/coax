# KTV-FSUSB2（EM2874版、バックエンド`fsusb2`）

| | |
| --- | --- |
| バックエンド | `fsusb2` |
| 対応OS | Linux / Windows / macOS（直接USB）|
| 伝送方式 | ISDB-T |
| ファームウェア | 不要 |

EM2874 USBブリッジ、富士通MB86A20S／A21S復調器、NXP TDA18211HDまたはMaxLinear MxL135RFチューナーを直接制御します。
ブリッジは[US-3POUT](us3pout.md)と同じEM287x系なので、レジスタとI2Cの扱いは共通です。
製品ごとに異なるのは、電源投入の手順とI2Cクロックだけです。

各OSの前提は[os.md](../setup/os.md)にあります。

## 対応製品

| 製品 | VID:PID | チューナー本数 | 伝送方式 |
| --- | --- | --- | --- |
| KEIAN KTV-FSUSB2（K0905〜K1202）| `0511:0029` | 1 | ISDB-T |
| KEIAN KTV-FSUSB2/V3（K1205、K1206）| `0511:003b` | 1 | ISDB-T |

この製品には2種類の構成があり、USB IDが同じなので、接続時に判別します。
EEPROMの識別値を読み、それで分からなければチューナーが返すIDを読んで、次のどちらかに決めます。

| 構成 | 復調器 | チューナー |
| --- | --- | --- |
| 旧 | 富士通 MB86A20S | NXP TDA18211HD |
| 新 | 富士通 MB86A21S | MaxLinear MxL135RF |

MxL135RFはUS-3POUTのMxL136と同じ制御なので、同じドライバーを使います。

同じKTV-FSUSB2の名前でも、IT9175／IT9179版（`0511:0046`）は別のバックエンドです（[fsusb2i.md](fsusb2i.md)）。
見分け方は[fsusb2i.md#対応製品](fsusb2i.md#対応製品)にあります。

## 選局のたびの再校正

チャンネルを変えるたびに、チューナーの校正と復調器のレジスタ設定をやり直します。
シンセサイザーだけを動かすやり方では、安定して同期しないためです。
同期したかどうかは、復調器の捕捉シーケンスが9まで進んだかで判断します。

## ファームウェア

ファームウェアは要りません。
EM2874、MB86A20S／A21S、TDA18211HD／MxL135RFのどれもROMだけで動きます。

## 信号測定

C/Nは、MB86A20S／A21Sのカウンタを、Linuxの`cnr_to_db_table`と同じ折れ線で1/1000dB単位に線形補間した値です。
ロックしている間だけ報告します。
信号強度は報告しません。
この復調器が返せるのは相対値だけで、dBmの値にできないためです。
