# US-3POUT（バックエンド`us3pout`）

| | |
| --- | --- |
| バックエンド | `us3pout` |
| 対応OS | Linux / Windows / macOS（直接USB）|
| 伝送方式 | ISDB-T、ISDB-S（同時に受信できるのは片方）|
| ファームウェア | 不要 |

EM287x USBブリッジ、TC90522復調器、MxL136（地上）とTDA20142（衛星）を直接制御します。

各OSの前提は[os.md](../setup/os.md)にあります。

## 対応製品

| 製品 | VID:PID | チューナー本数 | 伝送方式 |
| --- | --- | --- | --- |
| DigiBest US-3POUT | `0511:0045` | 1（ISDB-T/S切替）| ISDB-T、ISDB-S |

実機で、ISDB-TとISDB-Sの受信と、bulkとisochronousの両方の転送を確かめています。

TC90522は地上と衛星の2つの復調コアを持ちますが、同時に動かせるのは片方だけです。
TSの転送方式は、起動時にEM287xの設定を読み、TSエンドポイントがbulkかisochronousかを見て選びます。

## ファームウェア

ファームウェアは要りません。
EM287xブリッジ、TC90522、MxL136、TDA20142のどれもROMだけで動きます。

## 信号測定

C/Nは、TC90522の生カウンタを伝送方式ごとの変換曲線に通した値です。
ロックしている間だけ読めます。
信号強度は取得できません。

## 制限事項

- 受信できるのはISDB-TとISDB-Sで、同時に受けられるのは片方だけです。
- ISDB-S3には対応しません。
