# Quixun QRS-UT100B（バックエンド`ut100b`）

| | |
| --- | --- |
| バックエンド | `ut100b` |
| 対応OS | Linux（直接USB）。WindowsとmacOSでは確かめていません |
| 伝送方式 | ISDB-T |
| ファームウェア | 要（`asv5211-firmware.bin`。`px3`と同じもの）|

ASV5211のUSBブリッジ、TC90522と同じ地上側のレジスタを持つ復調器、RFチューナー、ASIE5606を直接制御します。
ブリッジ、復調器、ASIE5606は`px3`と同じ部品なので、`px3`と同じ`asv5211`、`tc90522`、`asie5606`の処理をそのまま使います。
ファームウェアの送り込みも`px3`の手順です。
このボードだけのものは、RFチューナー、電源を入れる手順、TSにかかるDESを外す処理の3つです。

各OSの前提は[os.md](../setup/os.md)にあります。

## 対応製品

| 製品 | VID:PID | チューナー本数 | 伝送方式 |
| --- | --- | --- | --- |
| Quixun QRS-UT100B | `3275:7020`（ファームウェアを送ったあと）| 1 | ISDB-T |

実機1台をLinuxで使い、次のことを確かめています。

- 地上波の受信と、30分の連続受信（約1926万パケットで同期外れとTSの誤りはなく、CCの飛びが1か所）
- DESを外したTSのPATが正しく読めること（DESを外す処理そのものは、recfriioの出力と照らす試験があります）
- 内蔵のカードスロットで、B-CASカードの初期化コマンドが通ること

同じ作りとされる製品（SKNETのMonsterTV HDUSなど）は、実機が無いので対象にしていません。

## ファームウェア

接続した直後は、ASV52xxのコールドID（`1738:5211`）で見えます。
ここでは`px3`の製品と区別できません。
ファームウェアを送ると、基板のEEPROMに書かれた`3275:7020`で出直します。

送るファームウェアは`px3`と同じ`asv5211-firmware.bin`です。
入手方法は[firmware.md](../setup/firmware.md)にあります。
付属CDのドライバーにもファームウェアが入っていますが、`fwextract`では取り出せません。
PLEXのものでも、付属CDのものと同じように受信できることを確かめています。

`coaxd`は、一覧を作る前に`px3`の手順でコールドIDの機器へファームウェアを送ります。
このとき、UT100Bも`3275:7020`として起動します。
`--backend ut100b`で直接開くときも、UT100Bが見つからなければ、同じ手順でファームウェアを送ってから開きます。

## TSのスクランブル

TSは、復調器からASIE5606を通ってブリッジに届きます。
ASIE5606は、TSパケットのペイロード184バイトにDESをかけてから渡します。
ヘッダーの4バイトはそのままです。
`ut100b`はDESを外してからTSを渡すので、出力は普通のTS（B25のスクランブルはそのまま）です。

`px3`の同じ版のASIE5606は、レジスタ`0x05`に`0x20`を書くと、DESをかけずにTSを出します。
このボードで`0x20`を書くと、TSが出なくなります。
TSが出るのは`0x05`のビット7を立てたときだけで、そのときは必ずDESがかかります。
違いは、基板がASIE5606のどの出力をブリッジにつないでいるかにあると考えています。

レジスタ`0x10`〜`0x1f`をブリッジの保護付き書き込み（`asv5211.CardBus.WriteGuarded`）で書くと、DESの鍵は変わりますが、DESはなくなりません。
`ut100b`はこの書き込みをせず、鍵は固定の値のままにして外します。
一方、`0x10`〜`0x1f`に普通のI²Cの書き込みで0を書いておかないと、TSが出ません。
この書き込みでは鍵は変わりません。

## RFチューナー

RFチューナーは、復調器の中継（レジスタ`0xfe`）の先の`0xc0`にあります。
型番は分かっていません。
同じアドレスに来るMxL136、MxL301RF、NM120のどれとも、レジスタが合いません。
レジスタの値は、メーカーのドライバーが送るものをそのまま使っています。

チューナーには書き込むだけで、読み出しはしません。
レジスタのアドレスを書いてから読むという普通の読み方をすると、このチューナーは1バイトの書き込みを命令として受け取ります。
そうなると受信が止まり、電源を切るまで戻りません。

周波数は1/64MHz単位で設定できますが、メーカーのドライバーと同じく整数のMHzで選局します。
定義ファイルの473142857Hzなら、473MHzです。
1/7MHzのずれは、チューナーの中間周波数の側で吸収されます。

## カード

内蔵のカードスロットはASIE5606が受け持ちます。
`px3`と同じ`asie5606`のT=1で使います。
`coax card`と`coax pcsc`には、「Quixun QRS-UT100B Smart Card Reader」として出ます。

## 信号測定

C/Nは、TC90522の地上側の生のカウンターを変換曲線に通した値です。
ロックしている間だけ読めます。
信号強度は取得できません。

## 制限事項

- 受信できるのはISDB-Tだけです。
- `GAIN`と`LOOP_THROUGH`はありません。
- WindowsとmacOSでは確かめていません。WindowsでWinUSBを割り当てる`.inf`もまだありません。
