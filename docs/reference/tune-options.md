# 選局オプション

`coax tune`と`coax scan`が取る選局オプションをまとめます。
どれも定義ファイルのプロパティに対応していて、書式は[channel-files.md](channel-files.md)にあります。

## LNB給電（`--lnb-power`）

値は電圧ではなく段で、`off`、`low`、`high`のどれかです（`0`は`off`、`11`と`13`は`low`、`15`と`18`と`on`は`high`の別名）。
出せる電圧はチューナーごとに違います（ISDB-S系のボードは11Vと15V、DVB-S系は13Vと18V、PLEX系のUSBは入切のみ）。
そのため数値も段の名前として扱い、指定した数値がそのまま出力電圧になるとは限りません。

省略すると給電しません[^defaults]。
給電が要る同軸では`--lnb-power high`を書いてください。
指定を忘れた場合も、ロックしただけでTSになっていないストリームは`no_sync`エラーになるので、空のファイルが作られることはありません。
給電を切れないチューナーに`off`を指定すると、エラーになります。
バックエンドごとの対応は[channel-files.md](channel-files.md#バックエンドごとの対応)にあります。

## LNBf（`--lnbf`）

給電とは別のもので、意味も別名も`dvbv5-zap`の`-l/--lnbf`と同じです。
`--freq`にダウンリンク周波数を書くときに指定します。
省略すると衛星の周波数を第1中間周波数として扱うので、日本のISDB-Sの定義ファイルは指定なしで通ります。

日本のDVB-S2の放送は`JCSAT3A`（128度）と`JCSAT4A`（124度）で、どちらを受けるかは22kHzトーンで切り替えます。
現行の伝送諸元はDVB-S2 / 8PSK / 23303kSps / FEC 3/5、偏波は直線偏波です（[channel-files.md](channel-files.md#lnbとダウンリンク周波数)）。

## フロントエンドの利得（`--gain`）

`auto`、`min`、`max`か、`+13dB`のような単位付きの値を取ります。
アンテナからの入力が強すぎて、フロントエンドが飽和するときに絞るための設定です。
値を書くと、ハードウェアが持ついちばん近い設定に合わせ、選ばれた値が`coax list`の`settings`に出ます。
段の番号は受け付けません（デバイスによって意味が変わるため）。

効くのは、Linuxの`dvb`、PX-MLT系、PX-S3U、S3U2、W3U2、W3U3の地上側、`px4`と`isdb2056`の衛星側だけです。
設定を持たないチューナーに指定すると、`409 unsupported`（`reason`は`gain`）を返します。
どのチューナーに何が書けるかは`/tuners`の`controls`に出ます（[tuner-host.md](tuner-host.md#tunersid)）。
定義ファイル側の`LNA`キーも同じ設定として読みます（[channel-files.md](channel-files.md#gainとlna)）。

## チューナーの優先順位（`--priority`）

整数で、既定は0です。
空いているチューナーが無いときに限り、自分より小さい値で使っているクライアントからチューナーを奪います。
同じ値どうしでは奪わず、先に確保したクライアントが使い続けます。

```console
$ coax tune --ch 27 --priority 10 -o rec.ts   # 録画は優先度10にする
$ coax scan --priority -5                     # スキャンは-5にして、ほかに譲る
```

チューナーを奪われた側のストリームは、その時点で終了します。
誰がどの優先度で使っているかは、`coax list`と`GET /tuners`の`priority`で分かります。
HTTPでは`X-Coax-Priority`ヘッダとして送るので、他のクライアントからも同じように使えます（[tuner-host.md](tuner-host.md#優先度x-coax-priority)）。

## 同期検査を外す（`--no-sync`）

既定では、`coaxd`がストリームの先頭を検査します。
TSなら`0x47`が188バイト間隔で並んでいるか、ISDB-S3なら`0x7f`から始まるTLVパケットが、ヘッダーに書かれた長さどおりに連続しているかを検査します。
条件を満たさなければ、データを1バイトも送らずにエラーを返します。
信号の無い同軸でも復調器はロックしてノイズを出力するので、それを録画してしまわないための検査です（[tuner-host.md](tuner-host.md#同期検査)）。
チューナーが実際に何を出しているか見たいときだけ`--no-sync`で外してください。

[^defaults]: recpt1、recdvb、recisdbも給電しないのが既定です。
